# QA 포트폴리오

안녕하세요. QA 엔지니어 권기일입니다.
본 레포지토리는 QA 업무 수행 과정에서 작성한 테스트 산출물, Jira 활용 경험, 자동화 연동 프로젝트 및 교육 결과물을 정리한 포트폴리오입니다.



# 주요 경험 요약

- Jira 기반 테스트 관리 및 버그 트래킹 수행

- Jira Webhook을 활용한 Synology Chat 알림 자동화 환경 구축 참여

- 테스트 케이스(Test Case) 설계 및 테스트 수행 경험

- 게임 QA 및 서비스 QA 관련 버그 리포트 및 분석 경험

- QA 교육 과정 및 실습 결과물 정리

  

# 프로젝트

## Jira Webhook 연동 프로젝트

 [프로젝트 바로가기](./Jira/jira-webhook)

**개요**

Jira에서 발생한 이슈 이벤트를 Webhook으로 수신하여 NAS 서버를 통해 Synology Chat으로 알림을 전송하는 자동화 환경 구축 프로젝트입니다.

**역할**

- Jira Webhook 구조 이해 및 설정
- Webhook 동작 테스트 및 검증
- 알림 수신 프로세스 확인 및 운영 테스트

**기대 효과**

- 이슈 발생 시 실시간 공유 가능

- QA 및 개발팀 간 커뮤니케이션 효율 향상
